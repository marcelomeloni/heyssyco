# Heyssy Co.

## Um sonho que começou aos 15 anos

Heyssy Co. não nasceu como um projeto de portfólio.  
Não nasceu como um estudo de caso.  
Nasceu como um sonho adolescente.

Este repositório guarda a primeira versão do site da Heyssy Corporation, criado quando eu tinha apenas 15 anos. Na época, meu conhecimento em desenvolvimento web era extremamente básico. Eu estava aprendendo sozinho, testando, errando, quebrando coisas e tentando fazer tudo funcionar “na marra”.

O código tem falhas.  
A estrutura não é perfeita.  
A lógica poderia ser melhor.

Mas cada linha aqui representa tentativa, curiosidade e ambição.

Esse projeto não está aqui porque é tecnicamente impecável.  
Ele está aqui porque foi o começo.

---

## A ideia por trás da Heyssy

Heyssy Corporation era minha marca de camisetas streetwear.

Eu criava os próprios designs, desenvolvia as artes, organizava os drops e revendia as peças. A ideia era construir algo com identidade própria, algo que tivesse personalidade e representasse minha visão estética naquela fase da vida.

O site foi criado para dar vida a essa marca:

- Página inicial com carrossel  
- Página de shop com listagem de produtos  
- Páginas individuais para cada camiseta  
- Simulação de seleção de tamanho e disponibilidade  
- Estrutura visual inspirada em marcas de streetwear  

Era simples, mas era real.

---

## Stack utilizada

Na época, eu não conhecia frameworks, não utilizava bibliotecas modernas nem padrões estruturados.

Foi tudo feito com:

- HTML puro  
- CSS puro  
- JavaScript puro  

Sem React.  
Sem backend estruturado.  
Sem banco de dados real.  
Sem boas práticas consolidadas.

A lógica de disponibilidade, preço e interação foi simulada diretamente no front-end. Hoje eu faria diferente. Mas naquela época, aquilo já era um grande passo.

---

## Estrutura do Projeto

O projeto é totalmente estático e composto por múltiplas páginas HTML:

- `index.html` — Página inicial com carrossel  
- `shop.html` — Listagem de produtos  
- `clownarabic.html` — Página de produto  
- `angel.html` — Página de produto  
- `tiopatinhas.html` — Página de produto  
- Pastas de imagens organizadas por coleção  
- CSS separado para estilização  
- Scripts JavaScript embutidos nas páginas  

É um reflexo direto de como eu entendia desenvolvimento web naquele momento.

## O que esse projeto representa hoje

Esse repositório é um marco pessoal.

Ele mostra:

- O começo da minha jornada com desenvolvimento  
- Minha primeira tentativa de criar algo comercial  
- Meu primeiro contato com estrutura de e-commerce  
- Meu interesse por design, produto e identidade visual  

A intenção não é apenas preservar por nostalgia.  
A ideia é, eventualmente, reconstruir algo em cima disso.

Reimaginar a Heyssy com o conhecimento que adquiri ao longo dos anos.  
Aplicar arquitetura melhor.  
Criar um backend real.  
Estruturar um sistema de vendas de verdade.  

Transformar aquele sonho adolescente em algo tecnicamente sólido.

---

## Por que manter isso público?

Porque evolução importa.

É fácil mostrar apenas projetos prontos e bem estruturados.  
Mais difícil é mostrar de onde tudo começou.

Esse projeto é um lembrete de que:

- Todo desenvolvedor começa sem saber  
- Todo código inicial é imperfeito  
- Errar faz parte do processo  
- Evolução é construída com prática  

Heyssy Co. foi o início.

E todo início merece ser lembrado.
